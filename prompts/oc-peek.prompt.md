> If the `openclew` command is not found, run it through npx: `npx openclew <command>`.

Run `openclew peek` to list the instruction file and all available docs.

Display the instruction file (AGENTS.md, CLAUDE.md, etc.) in full — do not summarize. Then display the ref list as-is. Do not read the refs at this stage — list file names only.
